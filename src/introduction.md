# Introduction

**Glide** is a tiny, reactive state manager for modern web apps. It pairs a structurally
shared store with framework-native bindings so your components stay fast without manual
memoization.

This site is a demo of a clean, modern mdBook theme. Browse the sidebar to explore the
(fictional) Glide documentation, or jump straight to the [Quickstart](./getting-started/quickstart.md).

## Why Glide

- **Minimal API.** One `createStore` call, one `useStore` hook.
- **Fine-grained.** Only components reading a changed slice re-render.
- **Framework agnostic.** First-class bindings for React, Vue, and Svelte.
